# 리뷰 카드 프로필 이미지 기본 표시

- 리뷰 카드 상단 아바타는 `review.profileImageUrl`을 사용하며 체크박스 선택과 무관합니다.
- 일반 HTTPS 이미지 URL과 네이버 기본 `data:image/...;base64` 이미지를 기존 검증 함수로 확인합니다.
- 이미지가 실제로 없거나 브라우저에서 로딩 실패 시에만 기존 사람 아이콘을 표시합니다.
- `프로필 이미지 경로(URL)` 체크박스는 별도 항목 출력/복사 및 전체 TXT·Excel 내보내기에만 영향을 줍니다.
- 수집한 리뷰 정보 자체와 기존 300개 기본 수집 설정, 2열 sticky 레이아웃은 변경하지 않았습니다.
