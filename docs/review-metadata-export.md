# 리뷰별 정보 선택 및 TXT 추출

`리뷰 수집하기`를 누른 후 `내보낼 정보 선택`에서 체크박스를 조정합니다. 미리보기·복사·TXT 파일은 동일한 선택값을 사용합니다.

- 초기 선택은 `리뷰 내용`만 켜집니다. 이전과 같은 `1.\n리뷰 본문` 형태로 출력됩니다.
- `전체 선택` / `전체 해제`로 빠르게 변경할 수 있습니다.
- 항목별 `n / 전체 수`는 해당 정보가 실제로 확인된 리뷰 개수입니다.
- **지원 항목:** 리뷰 본문, 닉네임, 프로필 사진 URL, 프로필 링크, 작성일, 방문일, 방문 횟수, 리뷰어의 리뷰 수, 별점, 키워드, 리뷰 사진/미디어 URL, 사진 수, 개별 리뷰 URL, 리뷰 ID, 방문 인증, 사장님 답글.
- 네이버 페이지에서 제공되지 않거나 해당 선택자로 확인하지 못한 항목은 표시하지 않습니다. 작성일과 방문일을 혼동해 추정하거나 사진 파일을 다운로드하지 않습니다.
- 기본 수집 대상은 기존과 동일하게 **본문이 있는 방문자 리뷰**입니다. 사진만 있는 리뷰 등은 수집 대상이 아닙니다.
- 네이버의 화면 구조·업종에 따라 확인 가능한 항목과 실제 검출률이 다릅니다. 디자인 개편 시 `lib/review-details.ts`의 선택자를 보완해야 할 수 있습니다.
- 여러 리뷰의 본문이 같더라도 작성자·날짜가 다르면 각각 남깁니다. 이미 수집되었던 `reviews: string[]` 응답도 하위 호환을 위해 유지합니다.

## 개발자 확인

Node.js 22 이상에서는 아래 단위 테스트를 실행할 수 있습니다.

```bash
node --experimental-strip-types --test tests/review-export.test.mjs
npm run lint
npx tsc --noEmit
```

라이브 네이버 사이트에서 Playwright를 실행하는 종단간 테스트는 이 패키지에서 수행하지 않았습니다. 실제 사이트의 DOM 변경 가능성을 감안해 실사용 장소에서 각 항목의 검출 여부를 확인해 주세요.
