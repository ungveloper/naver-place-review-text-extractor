# 리뷰 카드 미리보기 / 고정 내보내기 도구

## 화면

- 수집 전 중앙 입력 / 기본 수집 300개(직접 수정 가능), 수집 중 스피너와 진행률은 기존 그대로입니다.
- 완료 후 왼쪽의 선택 패널은 데스크톱 화면에서 `position: sticky`와 패널 내부 스크롤을 사용합니다.
- 오른쪽 미리보기 상단의 **텍스트 복사 / TXT 다운로드 / Excel 다운로드** 도구모음도 스크롤 위치에 고정됩니다.
- `<textarea>` 대신 리뷰별 카드를 표시합니다. 첫 20개를 그린 후 **리뷰 20개 더 보기**로 추가 표시합니다. 이는 화면 렌더링만 제한하며, 복사/TXT/Excel에는 전체 수집 데이터가 사용됩니다.
- 카드에서는 사용자가 체크한 정보만 레이블과 별도 값 영역으로 표시하며, 항목 오른쪽 **복사**는 해당 값만 전체 복사합니다.
- 프로필 사진 / 닉네임 / 리뷰 작성 정보 / 방문 정보 / 키워드 / 사진을 네이버 플레이스 리뷰와 유사한 구조로 표시합니다. 수집되지 않은 값은 임의로 채우지 않습니다.
- 네이버 기본 프로필 이미지의 `data:image/png;base64,...` 문자열은 매우 깁니다. 화면에서는 일부만 표시하며 **전체 데이터 펼치기**와 **복사**로 원본 전체에 접근할 수 있습니다. 이미지는 사진 자체로도 표시됩니다.

## 기존 내보내기 유지

`formatReviewExport`과 `buildSelectedReviewSheet` 및 `generateReviewXlsx` 코드는 변경하지 않았습니다.
전체 **텍스트 복사 / TXT 다운로드**는 이전 `번호 + '- 라벨: 값'` 텍스트 형식이고, **Excel 다운로드**는 기존 항목별 열 형식입니다. 카드의 **개별 복사**만 라벨 없이 순수 값만 복사합니다.

## 확인

```bash
node --experimental-strip-types --test tests/review-preview.test.mjs
npm run lint
npx tsc --noEmit
npm run build
```

본 변경은 화면 컴포넌트에 한정합니다. 네이버 사이트의 HTML/데이터 수집 선택자는 수정하지 않았습니다.
