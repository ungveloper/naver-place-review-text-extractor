# 리뷰 수집 화면 및 선택 필드 Excel 다운로드

## 화면 흐름

1. **수집 전**: 화면 중앙에 네이버 플레이스 ID/URL 입력 필드와 `리뷰 수집하기` 버튼만 표시합니다.
2. **수집 중**: 같은 위치에 로딩 스피너, 수집 단계, 수집 개수, 요청한 최대 개수 대비 진행 표시줄을 보여줍니다. 요청한 최대 개수는 실제 존재하는 리뷰 총개수가 아닐 수 있으므로 '목표 수 대비 수집 현황'으로 표시합니다.
3. **수집 완료**: 데스크톱에서는 좌측 정보 선택 패널, 우측 미리보기/다운로드 패널의 두 열로 전환됩니다. 모바일 화면에서는 위아래로 배치됩니다.

## 결과 페이지

- 좌측에서 기존 16개 리뷰 정보 체크박스를 여러 개 선택할 수 있습니다.
- 체크 결과는 우측 미리보기와 두 가지 내보내기 파일에 즉시 동기화됩니다.
- 우측 미리보기 상단의 버튼은 **텍스트 복사**, **TXT 다운로드**, **Excel 다운로드**입니다.
- TXT에는 미리보기와 동일한 문자열이 저장됩니다(UTF-8 BOM 포함).
- XLSX는 Excel/Numbers/LibreOffice에서 열 수 있는 표준 Office Open XML 형식입니다. `번호` 열 뒤로 선택한 항목을 열 제목으로 사용하고, 리뷰별 한 행에 값을 배치합니다.
- 일부 값이 없는 리뷰는 해당 Excel 셀을 비워 둡니다. 선택한 항목이 모두 비어 있는 리뷰는 TXT처럼 행 자체를 생략하고 원래 리뷰 번호는 유지합니다.
- 리뷰 문자열은 수식으로 실행되지 않도록 Excel 텍스트 셀로 저장합니다.
- 리뷰 추가 수집이 필요하면 헤더의 `다른 플레이스 수집`을 누릅니다. 결과 페이지에서 `수집 개수` 값을 변경하면 다음 수집에 적용됩니다.
- 수집 오류 시 최초 입력 화면으로 돌아와 오류 메시지를 표시합니다.
