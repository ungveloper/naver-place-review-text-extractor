# 기본 수집 개수 및 네이버 기본 프로필 이미지 지원

- 기본 수집 개수를 **100 → 300개**로 변경했습니다. 허용 범위는 기존대로 1~500개이며, 첫 화면에서 수집 개수를 직접 바꿀 수 있습니다.
- 기존 일반 프로필 이미지의 HTTP/HTTPS 경로는 그대로 유지됩니다.
- 네이버 기본 프로필 사진이 `<img src="data:image/png;base64,...">`처럼 인라인 이미지로 들어 있는 경우, 그 이미지 자체를 **data URI 문자열**로 제공합니다. 네이버에서 실제 제공하지 않는 이미지 주소를 만들어내지 않습니다.
- `data:image/...;base64,...`는 일반 웹 URL이 아니라 인코딩된 이미지 데이터 전체이기 때문에 **TXT, 클립보드, Excel 셀 내용이 길어질 수 있습니다.** 복사한 값은 데이터 URI를 지원하는 브라우저 등에서 이미지로 사용할 수 있습니다.
- 프로필 이미지의 `data:image/...`만 허용하며 리뷰 사진/미디어의 데이터 URI는 추출하지 않습니다. 원격 URL이 우선 확인되면 원격 URL을 반환합니다.
- 실제 이미지 태그/소스가 전혀 없는 경우는 여전히 비어 있으며, 임의의 사용자 프로필 이미지나 가상 경로를 채우지 않습니다.
- 이번 패치는 `lib/review-config.ts`, `lib/review-details.ts`만 수정합니다. UI, Excel 파일 형식, 기존 선택 항목 및 텍스트 출력 방식은 바꾸지 않습니다.

```bash
node --experimental-strip-types --test tests/review-default-avatar.test.mjs
```
